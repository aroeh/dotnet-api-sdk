# dotnet-api-sdk
This repo provides common building block SDKs for development of Dotnet APIs.  The provided SDKs can be used to add services in a flexible manner without having to write custom middleware and extensions.

There are SDKs for the following:
1. Dotnet API
2. Dotnet MongoDb SDK
3. Dotnet EFCore MSSQL SDK
4. Dotnet Redis SDK

There is also a demo API project utilizing the projects as both a way to illustrate how to use the SDKs but also to use for development and debugging.
